Preguntas frecuentes

Graba un ID único en el ESP32, regístralo en la vista Sensores y haz que el backend entregue lecturas para ese sensorId.
Porque el ID está registrado en frontend, pero todavía no llegó una lectura real desde el backend.
En Informes selecciona ID de sensor, ID de parcela, subcelda opcional y periodo. Luego genera HTML, CSV o vista imprimible PDF.

Guía rápida

Primero configura backend, luego agrega IDs de sensores y parcelas, después actualiza datos para visualizar todo en tiempo real.
